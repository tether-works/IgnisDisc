## IgnisDisc v1.18

Free, open-source (GPL-3.0-or-later) CD/DVD burner, DVD-Video authoring tool, audio CD ripper and multi-disc archiver for Windows 10 and 11 (x64).

### Downloads and SHA-256 checksums
- **Installer** (`IgnisDisc-Setup.exe`, per-user, no admin rights): checksum added once the release build finishes
- **Portable** (`IgnisDisc-Portable-win-x64.zip`): checksum added once the release build finishes

Builds are not code-signed yet, so Windows SmartScreen may warn on first run.

### Audio CD ripping and checking
- **CUETools Database (CTDB) check and repair** (`rip-audio --verify-ctdb`, off by default). The rip is compared with the database's track and disc checksums. When the rip differs, the database's repair data can fix it, and the fix is kept only when AccurateRip then agrees. On a real CD the check matched the database, and the repair data matched IgnisDisc's own calculation. The repair fixed a real rip with damage added afterwards (zeroed sectors, flipped samples) against the live database. It has not met a physically scratched disc yet.
- **Ripping options**: several formats from one rip, a library folder (`Artist\Album (Year)\NN - Title` by default, or your own naming template), release year, front cover from the Cover Art Archive, `folder.jpg`, and MP3 as constant bitrate or VBR (V0-V9). When MusicBrainz lists editions that name tracks differently, the rip stops before reading the disc and asks which edition you have.
- **Convert Audio** (`convert-audio`, and a tab in the app) converts audio files already on disk, keeping their tags and cover. It never writes over an input file.
- The 1-click ffmpeg download is now preferred over an `ffmpeg.exe` left in the program folder.

### Mixed-mode, Enhanced and multi-session CDs
- **Mode 2 / CD-ROM XA data track** as track 1 of a mixed CUE sheet, and the write-offset correction now moves the audio part of a mixed-mode disc only.
- **Enhanced CD (CD-Extra)**: burn a folder as the data session after the music, with an optional Blue Book layout (off by default). Disc copy can copy an Enhanced CD whole, session by session.

### Picture discs and Rosetta discs (experimental)
- **Disc Art page** in the app and `disc-art generate`, `preview`, `burn` and `calibrate` on the command line: place one picture (scale, move, rotate, fit to the ring or the disc), set its tone, limit it to a band between two radii, and burn it. A title ring writes the title and date at the outer edge of a DVD picture disc. A rim header (title, date, checksum prefix, 5-degree ticks) can be drawn on CD, DVD and BD-R picture discs.
- **Fill empty space with a picture** on Data Disc, DVD-Video and Audio CD burns (off by default). The files or music are written as usual and a picture is drawn on the rest of the disc. On an audio CD the picture goes into a second, data session, so players still see the same track list. A picture can also be hidden in the pre-gap before track 1 (experimental; some players and rippers play it as noise).
- **Two-session picture burn** on DVD-R and DVD+R: the picture first, the files at the outer edge afterwards.
- **Calibration screen**: load a photo of a burned disc, rectify it, click reference points and save the fit that later burns use.
- **`rosetta build` and `rosetta burn`**: a hybrid disc with the archive inside and readable text pages on the surface, in Hobbyist and High-density presets, on DVD-R and on CD-R.
- Burns whose write offset is not a multiple of 6 are refused for pre-gap pictures, and a picture burn checks temp space before starting.

### Drives
- The drive capability list shows only disc types the drive has profiles for.
- A disc whose speed cap is below the drive's slowest speed now says so.
- A second drive (Lite-On iHAS124) has been connected and probed read-only. Nothing has been written with it yet.

### Fixed
- The CD 80-minute preset geometry and the edges of the CD interleaver (both used only by picture and Rosetta discs).

### Known limitations
- Builds are unsigned, so Windows SmartScreen warns on first launch.
- **Picture discs and Rosetta discs have run only on generated images and in the built-in drive simulator, apart from one real burn:** a CD-RW in an LG GP60NB50, with an uncalibrated `cd-80` geometry and a rim header. No picture showed. The surface had fine concentric stripes, which is how an angle drift from an uncalibrated track pitch or speed looks, and the read-back stopped partway. A calibration is needed first. Where a picture lands on a real disc has not been seen, and no result has been looked at under a microscope.
- Mode 2 / CD-ROM XA data tracks, write-offset correction on mixed-mode discs, the Blue Book layout, copying an Enhanced CD, and gap detection when ripping have run only in the built-in drive simulator, not on real discs.
- Direct drive commands have run on real hardware on one drive model only (LG GP60NB50). DVD-RAM, dual-layer DVD-R, Blu-ray, CD-Extra / Audio CD PAR2 recovery sessions, archive `HEALTH.json` certificates and `eject` / `load` have run only in the simulator or against image files.
- The new DVD-Video authoring options have been checked in tests only; no disc made with a non-default choice has been burned or played. No disc with generated subtitles has been played in a stand-alone player. No audio CD from this release has been checked in a stand-alone CD player.
- Leaving a DVD-RW open needs a full erase first (about 30 minutes on a 2x disc); after adding a session to a DVD-RW or DVD-R, Windows may need the disc reinserted to show the new files; open multi-session discs keep Joliet file names of up to 64 characters.
- DiscJuggler `.cdi` support was checked only on hand-built files following the published format.
- On slim USB drives with spring-latched trays, a laser-off `--test-first` run still stops after the test write so the user can open and close the tray by hand.
